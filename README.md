# UML Diagram Generator

Professional interactive UML Class Diagram Generator built with React, Vite, and @xyflow/react.

## Projects & Directories
- [**uml-class-diagram-generator-pro**](./uml-class-diagram-generator-pro) - Interactive studio for creating, editing, and exporting UML class diagrams.

---

## Quick Start

Navigate to the project directory:
```bash
cd uml-class-diagram-generator-pro
```

Install dependencies:
```bash
npm install
```

Start development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```
